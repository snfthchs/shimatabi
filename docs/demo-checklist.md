## 注意と、見つかったこと

- **デモは、午後の便が始まる前に、シードを入れ直して行う。** シードは、実行した時刻より後の今日の便だけを作る。夕方以降に入れると、「今日の午後」の便がなく、デモの最初の質問（項目1）で、提案が出ない。デモの直前に、次を実行する。

  ```bash
  cd backend && .venv/bin/python -m app.seed --reset
  ```

- **電話番号は、ハイフンなしで保存される。** APIが、受け取った電話番号を、空白・ハイフンを取り除いた形にして保存するため、事業者の画面の伏せ字は `090****5678`（設計の例は `090-****-5678`）、平文は `09012345678` と表示される。動作に問題はないが、見た目が設計の例と違う。直すかどうかは、本格開発の前に決める（`summary.md` の「次の一手」に入れた）。
- 手元で確認したのは、Chromium系のブラウザ（Claude のアプリ内ブラウザ）だけである。
