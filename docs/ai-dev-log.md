# AI開発ログ

AIとの開発で起きたことを記録して、ルールの改善につなげる。開発に関することだけを書く（公開前提）。

## 記録
| 日付 | Issue / PR | 起きたこと | 原因 | 対策（追加したルールなど） |
|---|---|---|---|---|
| 2026-11-23 | #1 / #2 | コミットの作成者情報に、実名とマシン名を含む自動設定の値が入った。`main` へpush済みのコミットも含まれていたため、履歴を書き換える（`--force-with-lease`）ことになった | gitの `user.name` と `user.email` が、リポジトリにもグローバルにも未設定で、OSのアカウント情報から自動で作られた値が使われた。コミット前に作成者情報を確認する手順がなく、AIはコミット後のgitの警告で気づいた | 今回は、リポジトリ内の設定を `isa` とGitHubのnoreplyアドレスに変更し、既存のコミットを作り直した。今後は、コミット前に作成者情報を確認するルールを、ai-config か `AGENTS.md` に追加することを提案する（人間の判断を待っている） |
| 2026-11-23 | #1 / #2 | 作業ブランチ `docs/1-design-phase` を、`main` から直接切った。人間から「`main` → `develop` → 作業ブランチの順で切る」という運用の指示があり、今後に適用することになった | 既存のルール（ai-config の git ルール）に、`develop` を経由するブランチの切り方が書かれておらず、AIが知らなかった | 今後の作業から、`develop` を経由して作業ブランチを切る。AIのメモリに記録した。ルールとして、ai-config か `AGENTS.md` に追加するかは、人間と相談する |
